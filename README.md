# OiKID Reading Coach

This repository stores verified OiKID reading coach pages.

Current content:

- `output/taskpacks/` - older OiKID taskpack HTML/Markdown artifacts kept for reference.
- `output/oikid/` - current weekly OiKID preview and review HTML pages generated by Codex automation.

The active automation lives outside this repository in Codex. It generates and verifies HTML pages from the local OiKID downloads folder, then commits only the verified HTML files here.
